TYPOGRAPHY
Use READex Pro as the primary typeface for the Arabic and Latin interface.

Typography principles:
- use Readex Pro consistently across the system
- use only a small number of weights
- 400 for body text
- 500 for navigation, metadata and controls
- 600 for headings and key emphasis
- avoid unnecessary bold text
- avoid condensed Arabic typography
- avoid decorative Arabic display fonts for UI
- prioritize calm reading rhythm and excellent Arabic rendering

Use a carefully tuned line-height system.
Arabic text should never feel vertically cramped.
Do not use tiny text for important information.

PSYCHOLOGY / BEHAVIORAL DESIGN

Use ethical behavioral principles:

1. COGNITIVE FLUENCY
Make information easy to understand.
Avoid ambiguous wording.
Prefer obvious labels.

2. CHOICE ARCHITECTURE
Do not overwhelm customers with hundreds of choices immediately.
Guide them through categories, filters and optional discovery tools.

3. INFORMATION PROGRESSIVE DISCLOSURE
Show the most important decision information first.
Reveal deeper specifications when needed.

4. SOCIAL PROOF
Use authentic reviews, customer photos and real usage examples.

5. AUTHORITY / EXPERTISE
Demonstrate knowledge through accurate fabric specifications and educational content rather than exaggerated claims.

6. LOSS-AVERSION WITHOUT MANIPULATION
Make real consequences visible:
- low stock when genuinely low
- shipping deadlines when genuine
- minimum order quantities
- return conditions

Never invent urgency.

7. ANCHORING ONLY WHEN LEGITIMATE
Show comparison or previous prices only when they represent genuine pricing history or a real reference price.

8. RISK REDUCTION
Before purchase, answer the questions that create uncertainty:
- What is it made of?
- How wide is it?
- Does it stretch?
- Is it transparent?
- What does it look like close up?
- How does it drape?
- How much does delivery cost?
- What happens if there is a problem?

9. COMMITMENT & PROGRESS
Make checkout feel finite and understandable.
Show clear progress instead of making the user wonder how many steps remain.

10. RECENCY / DISCOVERY
Use "جديد" or "وصل حديثًا" only for genuinely new stock.

11. PERSONAL RELEVANCE
Recommend products based on useful relationships:
same color, same use case, similar material, complementary fabric.

12. NO DARK PATTERNS
Absolutely prohibit:
- fake countdowns
- fake stock numbers
- fake reviews
- hidden fees
- preselected unwanted extras
- disguised advertising
- forced account creation
- confusing cancellation
- misleading price comparisons

ACCESSIBILITY

Design toward WCAG 2.2 AA.

Requirements:
- strong text/background contrast
- visible keyboard focus states
- accessible form labels
- clear error states
- no color-only communication
- logical heading hierarchy
- accessible icon buttons
- semantic interaction patterns
- comfortable touch targets
- full RTL support
- readable Arabic at zoom
- support reflow without destroying functionality
- no essential content hidden only inside hover interactions

Do not sacrifice accessibility for visual minimalism.

PERFORMANCE-FIRST DESIGN

The visual system must be created with real implementation performance in mind.

Target Core Web Vitals:
- LCP <= 2.5s
- INP <= 200ms
- CLS <= 0.1

Performance principles:
- do not design around giant background videos
- avoid excessive animation
- avoid large image walls above the fold
- use responsive image crops
- reserve image dimensions to prevent layout shifts
- compress imagery appropriately
- prefer AVIF/WebP where supported
- lazy-load below-the-fold images
- do not lazy-load the primary above-the-fold hero/LCP image
- keep the primary hero asset intentionally lightweight
- use a limited font family
- use only necessary font weights
- self-host/subset WOFF2 fonts where practical
- avoid unnecessary third-party scripts
- avoid visual components that require large JavaScript bundles
- do not create unnecessary carousels

The design should be beautiful because of hierarchy, composition, photography and typography—not because of expensive effects.

IMAGE PERFORMANCE RULES

- prioritize the primary visual
- avoid multiple competing large images

Never allow image loading to cause layout jumps.
